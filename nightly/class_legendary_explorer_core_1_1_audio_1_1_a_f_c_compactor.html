◆ missingAFCReferences

List<ReferencedAudio> LegendaryExplorerCore.Audio.AFCCompactor.missingAFCReferences
static

Compiles ReferencedAudio for every WwiseStream export in a given folder of package files.

This method will look for AFCs in the game's basegame folder, all official DLC folders, and the input folder

Parameters
gameGame you are operating on
inputPathPath to folder to scan for WwiseStreams. All subdirectories will be searched for .pcc files
notifyProgressCallback invoked after every package file is opened with (currentFileIndex, totalFileCount)
currentScanningFileCallbackCallback invoked after every package file is opened with the path to the current file
debugOutCallback invoked with debug information on every export scanned and every AFC found
Returns
A tuple of ReferencedAudios for which no AFC was able to be found, and ReferencedAudios with verified AFCs
