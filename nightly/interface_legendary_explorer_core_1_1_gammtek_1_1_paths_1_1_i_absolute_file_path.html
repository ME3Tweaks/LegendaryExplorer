Detailed Description

Represents an absolute path to a file on file system.

The path represented can exist or not. The extension method PathHelpers.ToAbsoluteFilePath(string) can be called to create a new IAbsoluteFilePath object from a string.

◆ GetRelativePathFrom()

new IRelativeFilePath LegendaryExplorerCore.Gammtek.Paths.IAbsoluteFilePath.GetRelativePathFrom ( IAbsoluteDirectoryPath pivotDirectory)

Compute this file as relative from pivotDirectory . If this file is "C:\Dir1\Dir2\File.txt" and pivotDirectory is "C:\Dir1\Dir3", the returned relative file path is "..\Dir2\File.txt".

This file nor pivotDirectory need to exist for this operation to complete properly.
