◆ MaterialShaderMap

LegendaryExplorerCore.Shaders.ShaderCacheManipulator.MaterialShaderMap
static

Gets shaders that aren't specific to a vertex factory, such as FLightFunctionPixelShader. They're in the material shader map itself, rather than one of its mesh shader maps.

Parameters
materialA Material, or a MaterialInstance with a StaticPermutationResource
getSeekFreeShaderCacheGets the parsed SeekFreeShaderCache of a package, or null if it doesn't have one. For callers that want to avoid re-parsing the same ShaderCache for each material in a package. If null, the package's ShaderCache is parsed.
shaderTypesThe FLocalVertexFactory shader types to retrieve
