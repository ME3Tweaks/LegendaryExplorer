Detailed Description

Read-only LE3 package session that reads texture properties without loading texture export payloads. Successful metadata is cached per export for this session. Caller resolves imports to the appropriate donor session/export. No automatic package discovery or persistent cache. Not thread-safe; do not edit/save the exposed header-only package or share its source stream.
