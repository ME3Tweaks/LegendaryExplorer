Detailed Description

Immutable, caller-owned LE3 shader-source set. Translation, D3D compilation and native source CRCs can share this identity without reopening mutable files between jobs. Flat native filenames are required; directory paths and duplicate case-insensitive names are rejected. This is not a shader-registry completeness or native bytecode-parity guarantee.
