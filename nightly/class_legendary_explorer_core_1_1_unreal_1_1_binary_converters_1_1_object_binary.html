virtual void LegendaryExplorerCore.Unreal.BinaryConverters.ObjectBinary.VerifyUIndexRefs ( MEGame game,
IUIndexRefVerifier verifier )
inlinevirtual

Calls IUIndexRefVerifier.Verify for every UIndex in this object that has been annotated with UIndexRefAttribute, passing along the class that UIndex is allowed to refer to.

Overrides of this are emitted by the LegendaryExplorerCore.SourceGenerators project.

Parameters
gameRestricts the UIndexes to the ones that exist on this game's version of the object, and picks the expected class for the ones that differ between games.
verifierThe IUIndexRefVerifier implementation whose Verify method will be called for every annotated uIndex.
