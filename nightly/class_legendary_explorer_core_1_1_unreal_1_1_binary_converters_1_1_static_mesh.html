Calls IUIndexAction.Invoke on every UIndex in this object. This can be used to change the UIndex, or to perform some action based on each one.

Template Parameters
TActionA readonly struct that implements IUIndexAction. Examples: UIndexZeroer, UIndexAndPropNameCollector
Parameters
gameRestricts the UIndexes to the ones that exist on this game's version of the object.
actionThe IUIndexAction implementation whose Invoke method will be called for every uIndex.
