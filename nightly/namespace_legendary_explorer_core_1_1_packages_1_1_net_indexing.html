A place where a linker declares its guid and net object count. The count is the last generation's NetObjectCount (the summary's for a package file, the export's GenerationNetObjectCount for a forced export), which is what UPackage::InitNetInfo reads; -1 means the export has none, which the engine treats as PKG_ServerSideOnly.
