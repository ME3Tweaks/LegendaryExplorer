PropertyCollection LegendaryExplorerCore.Packages.IEntryExtensions.GetCondensedProperties ( this ExportEntry export,
PackageCache packageCache = null,
bool resolveImports = false,
bool mergeStructs = false )
inlinestatic

Reads an export's properties, filling in missing values from its archetypes. The nearest value wins.

Parameters
exportThe export whose properties to read.
packageCacheThe cache used to read properties and resolve imported archetypes.
resolveImportsWhether to follow imported archetypes. Unresolved imports end the traversal.
mergeStructsWhether to recursively inherit missing fields in matching, non-immutable structs. Arrays and immutable structs are always inherited as whole values.

Imported archetypes can contribute properties from other packages. Object and delegate properties from those packages are omitted because their object indices are only valid in the source package; references are not relinked. Non-immutable struct fields are filtered recursively. Arrays and immutable structs containing such references are omitted as a whole to preserve their layout. The result may therefore be incomplete. Properties originating in the export's own package are not filtered.
