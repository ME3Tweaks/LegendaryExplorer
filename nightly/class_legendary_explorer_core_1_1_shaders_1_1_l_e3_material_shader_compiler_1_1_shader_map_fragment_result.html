Detailed Description

A serialization-ready fragment covering every eligible job in an explicit caller plan. IsCompleteShaderSet reports native required membership only for a plan that covers the native required set; it never authorizes installation. Source CRC maps and material-resource installation remain separate. Uniform-expression trees are shared with the translation; array/key containers are detached.
