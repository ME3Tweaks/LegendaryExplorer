Translates the currently supported LE3 expression subset and applies the result to the game's MaterialTemplate.usf text, with the native full-precision TexCoords substitution. This authored-root path omits resource input defaults and selection-color operations; use TranslateMaterialResourceHlsl for those. The template is supplied by the caller because the installed game owns it; LEC does not redistribute shader source.

The current subset is deliberately strict: constants, scalar/vector parameters, affine-unpack 2D/cube texture samples (including confirmed normal compression modes), Add/Multiply/ Subtract/Divide (including folded numeric uniforms), DotProduct, CrossProduct, Power, Clamp, Abs/Floor/Ceil/Frac, Sine/Cosine, SquareRoot, OneMinus, Time, Normalize, Fmod, AppendVector, LinearInterpolate, VertexColor, TextureCoordinate, StaticSwitchParameter, and ordinary/static component masks. Unsupported nodes or input features return errors and no HLSL.
