enum LegendaryExplorerCore.PlotDatabase.PlotElements.PlotElementType : int

Represents the type of a plot element, as found in the BioWare Plot Databases.

Enumerator
None 

No plot element type set.

Region 

A preset region of the game.

Plot 

A plot or sub-plot.

FlagGroup 

A group of flags.

Flag 

A flag, represented in-game as a boolean plot variable.

State 

A linear plot state (true or false), represented in-game as a boolean plot variable.

SubState 

A sub-flag or sub-state (either first or many trigger a state change), represented in-game as a boolean plot variable.

Conditional 

A boolean expression used to test a game state or set of states, represented in-game as a conditional function.

Consequence 

A set of actions to take upon state change, represented in-game as a plot transition.

Transition 

A method to call to set the value of various states.

JournalGoal 

The primary goal of an entire quest.

JournalTask 

A single task in a quest.

JournalItem 

A plot item.

Integer 

An integer, represented in-game as an int plot variable.

Float 

A floating point number, represented in-game as a float plot variable.

Mod 

A category for elements for a single mod or modder.

Category 

A category of various elements in a mod.
