Detailed Description

Resolved boundary for future MaterialInstance parent-chain/permutation resolution. The caller supplies the base graph and merged static parameters; this class does not resolve instance parents, determine whether an instance needs a shader map, or apply runtime scalar/vector/texture overrides. Static parameters are snapshotted, including override flags.
