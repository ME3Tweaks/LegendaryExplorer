Detailed Description

For use with List initializers.

var intList = new List<int>
{
1,
2,
3,
InitializerHelper.ConditionalAdd(shouldAdd465, () => new[]
{
4,
5,
6
}),
7,
8
}
//intList would only contain 4,5, and 6 if shouldAdd456 was true
