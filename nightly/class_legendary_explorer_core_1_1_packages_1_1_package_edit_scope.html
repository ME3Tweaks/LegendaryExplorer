Detailed Description

Makes a group of edits to one or more packages all-or-nothing. Unless Complete is called before it's disposed (such as when an exception escapes a using block), every package is put back exactly as it was when the scope began: its names, imports and exports, including entries appended or removed (by trashing) since, with the same entry objects at the same indexes. Change notifications to the package's users are held until the scope completes, and never sent if it's abandoned.

Edits must be made synchronously on one thread while the scope is open, and the packages can't be saved meanwhile. Rolling back restores package state only: objects built from the packages (such as parsed binaries or property collections) aren't updated.
