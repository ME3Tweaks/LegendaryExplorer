Attempts to resolve the import by looking at associated files that are loaded before this one, and by looking at globally loaded files.

Parameters
entryThe import to resolve
cachePackage cache that is used to improve performnace by not having to open all packages from disk. A TieredPackageCache is preferred.
localizationThree letter localization code, all upper case. Defaults to INT.
unsafeLoadIf we are only testing for existence; use unsafe partial load. DO NOT USE THE RESULTING VALUE IF YOU SET THIS TO TRUE
localDirFilesFiles in the local directory. These will be checked last
gameRootOverrideThe root path of the game. If null, the default path will be used
instancedFullPathOverrideAllows overriding the instanced full path for lookup when resolving this import - can be useful if you need to test an import that has it's IFP changed and would not resolve otherwise
Returns
