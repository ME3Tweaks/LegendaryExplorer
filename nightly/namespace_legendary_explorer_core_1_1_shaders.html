class  LE3MaterialUsageAdvisor
 Mirrors the shipping UMaterial::CheckMaterialUsage worker (0x7ff74ab2e260) as a pure query. The game never sets a usage flag at runtime: a use whose flag is clear either falls back to the default material (terrain foliage, lightmapped static meshes, decals, fog volumes) or reaches a fatal missing-shader error at draw time. The flags also select which vertex-factory shaders a complete shader map must hold, so set them before compiling. Read flags from the base Material; instances defer to it. More...
class  LE3MaterialUsageScanner
 Finds what each material in a package is drawn with, for LE3MaterialUsageAdvisor. Instances resolve to their base Material, since usage flags live there. Reports only uses it can see in this package; a material used from other packages needs those scanned too. Checked against every shipping LE3 package (LE3MaterialUsageScannerValidation): skeletal mesh, particle, beam, decal, fog, spline, morph, lens flare and material-effect uses match the shipped flags to within a few dozen of 550k. Lightmapped meshes report StaticLighting and VectorLightMaps; shipping leaves VectorLightMaps clear on about 3% of them, so that one is a deliberate superset. SimpleLightMaps and LightEnvironments are not derived: shipping leaves them clear on most uses. More...
