Detailed Description

Read-only LE3 source-CRC session. Uses the shipping lexical include walk, not D3D preprocessing: inactive/commented includes count, Material.usf becomes MaterialTemplate.usf, and the virtual VertexFactory.usf is excluded. This does not establish shader-registry completeness or parity. Create a new session after source changes; each session snapshots its loaded texts and results.
