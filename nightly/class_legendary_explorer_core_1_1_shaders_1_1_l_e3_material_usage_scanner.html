Detailed Description

Finds what each material in a package is drawn with, for LE3MaterialUsageAdvisor. Instances resolve to their base Material, since usage flags live there. Reports only uses it can see in this package; a material used from other packages needs those scanned too. Checked against every shipping LE3 package (LE3MaterialUsageScannerValidation): skeletal mesh, particle, beam, decal, fog, spline, morph, lens flare and material-effect uses match the shipped flags to within a few dozen of 550k. Lightmapped meshes report StaticLighting and VectorLightMaps; shipping leaves VectorLightMaps clear on about 3% of them, so that one is a deliberate superset. SimpleLightMaps and LightEnvironments are not derived: shipping leaves them clear on most uses.
