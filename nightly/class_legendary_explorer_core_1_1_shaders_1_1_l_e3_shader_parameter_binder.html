Detailed Description

Binds D3D-reflected allocations to LE3's serialized shader parameter structures without a game process. This is the shared material-binding layer, not a complete shader-type constructor. Policy-specific constructors must bind their own parameters and check UnboundParameters.

Decal factories' HLSL can allocate DecalLocalBinormal/DecalLocalTangent in the pixel stage, but the game's pixel shaders bind no vertex-factory parameters (the custom-lightmap base-pass pixel shader neither binds nor serializes them; only the decal vertex-factory binders name them).
