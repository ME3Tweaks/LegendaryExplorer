Finds existing ExportEntry or ImportEntry in pcc .

Parameters
pcc
instancedFullPathThe ifp of the object to find or add as an import.
classNameFound entry must be of this class. (Will disambiguate when two entries of different classes have the same ifp.) Also used in creation of ImportEntry if neccesary.
packageFileUsed in creation of ImportEntry if neccesary. Should be the packagefile the class is defined in.

if neccessary, will fill in parents as Package Imports (if the import you need has non-Package parents, ensure they exist first)

//Without the first two lines, the class and function entries would get created as Package Imports if they did not exist.
pcc.GetEntryOrAddImport("Engine.Actor", "Class");
pcc.GetEntryOrAddImport("Engine.Actor.SpecialHandling", "Function");
IEntry entry = pcc.GetEntryOrAddImport("Engine.Actor.SpecialHandling.ReturnValue", "ObjectProperty");
