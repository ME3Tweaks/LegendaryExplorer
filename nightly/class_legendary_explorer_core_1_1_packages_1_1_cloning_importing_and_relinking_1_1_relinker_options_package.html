Detailed Description

Specifies options used for relinking, as well as containing objects that can be passed through the entry porting process without having to modify method signatures.

Provides a way to override relinkUIndex() behavior. If not provided, the default implementation is used.

Parameters
importingPccPcc being imported from
relinkingExportThe export in the destination being relinked
uIndexThe source package uIndex. It should be changed to the destination package uIndex by the end of the call.
propertyNameName of the item being relinked (for messages)
prefixPrefix to put on the relink message (if any)
ropCustom ROP object, same as the one this method is attached to
resultThe resulting relink message if an issue occurred
Returns
True if the custom relink was used, false if it was not and the default relink logic will be used
