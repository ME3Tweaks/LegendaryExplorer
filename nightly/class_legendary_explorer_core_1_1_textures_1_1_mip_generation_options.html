Detailed Description

Controls how lower mips are generated by Image.correctMips and, through it, by texture replacement. A null or default instance reproduces the historical box-filtered chain exactly.

Strength of an unsharp mask applied to every generated level that is at least 4x4 (0 disables it). Trilinear sampling softens a texture by about half a mip, so a downscale that is exact for the pixel grid still looks soft on screen; roughly 0.5 - 1.0 compensates for that. ◆ PadTransparentColor

bool LegendaryExplorerCore.Textures.MipGenerationOptions.PadTransparentColor
get

Copies the colour of neighbouring visible texels into fully transparent texels (alpha <= 2), a few texels deep, in every generated level and in the source used to build them. This changes nothing that is drawn directly, but the game filters straight (non-premultiplied) RGB, so without it the black under a zero-alpha texel is mixed into every silhouette edge once the texture is minified or magnified. The top mip is only rewritten when it has to be converted to another format anyway.
