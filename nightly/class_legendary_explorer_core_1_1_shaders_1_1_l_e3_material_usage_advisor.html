Detailed Description

Mirrors the shipping UMaterial::CheckMaterialUsage worker (0x7ff74ab2e260) as a pure query. The game never sets a usage flag at runtime: a use whose flag is clear either falls back to the default material (terrain foliage, lightmapped static meshes, decals, fog volumes) or reaches a fatal missing-shader error at draw time. The flags also select which vertex-factory shaders a complete shader map must hold, so set them before compiling. Read flags from the base Material; instances defer to it.
