# LEGENDARY EXPLORER CONTRIBUTION GUIDELINES
This document outlines the basic details about how you can contribute to the toolset.

### Contributing code
If you'd like to contribute code, feel free to come to [the ME3Tweaks Discord server](https://discord.gg/s8HA6dc), where the development team and userbase for our tools reside. Code contributations are done through opening a pull request. Be aware this project is licensed as GPLv3 - any code you submit for pulls will be licensed under this. If your code is not compatible with GPLv3, it won't be accepted.

- __Fork the Beta branch__ &mdash; New code is pushed into the Beta branch before eventually being merged with the master (stable). Additional branches on this repository are sometimes made and are eventually folded (or abandoned) into the Beta branch. Nothing ever will directly commit to stable.
- __Examine the existing Issues__ &mdash; This is a great way to become familiar with current tasks and features on the roadmap. 

Only members of the ME3Tweaks development group have direct write access onto the repo.

### Restrictions on Generative AI Usage

Do not post output from Large Language Models or similar generative AI as comments on GitHub, as such comments tend to be formulaic and low quality. If you use generative AI tools as an aid in developing code or documentation changes, ensure that you fully understand the proposed changes and can explain why they are the correct approach. If we beleive you are unable to unable to understand your code we are likely to reject it. Code still takes resources to maintain once written.

Make sure you have added value based on your personal competency to your contributions. Just taking some input, feeding it to an AI and posting the result is not of value to the project. To preserve developer resources, we reserve the right to rigorously reject seemingly AI generated low-value contributions.

### Contributing other things
You might not be a coder, but you can still be useful. Documenting reproducable steps for bugs you encounter and other things go a long way in helping things get fixed. Submit issues to this repository for things that don't take divine intervention to implement and we'll see what we can do. 

### Things we're not supporting
Some things in the toolset we don't support, because we don't have the time or resources to do so.
 - Any platform besides PC. The current toolset has limited support for reading files from PS3, Xbox 360 and WiiU files, but it is very broken and will not be fixed.
 - Pirated user issues. If your game is pirated, don't bother asking for support if stuff is broken.
